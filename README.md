# Kuak World · Pixel Life Online

เกม open world 2D pixel แนว **The Sims × Stardew Valley × Minecraft** เล่นออนไลน์หลายคนในแผนที่เดียวกัน
(ไม่ใช้ asset ภายนอก กราฟิกทั้งหมดวาดด้วยโค้ด)

## รัน

```bash
./start-kuak-world.command        # ติดตั้ง dependency ครั้งแรกให้เอง แล้วเปิด http://localhost:4488
```

หรือ `PORT=4488 node server/index.js`

เล่นกับเพื่อนในวง LAN: ให้เพื่อนเปิด `http://<IP เครื่องนี้>:4488` · เล่นผ่านอินเทอร์เน็ต: deploy ขึ้น VPS หรือใช้ ngrok/cloudflared ชี้มาที่พอร์ต 4488

## ฟีเจอร์

- **Login/สมัครสมาชิก** (scrypt hash, token) → **สร้างตัวละคร** (สีผิว ทรงผม สีผม ตา เสื้อ กางเกง หมวก)
- **โลกใหญ่ 2048×2048 ช่อง** สร้างจาก simplex noise (ทะเล ชายหาด ทุ่งหญ้า ป่า ภูเขา หิมะ แม่น้ำ) โหลดเป็น chunk 32×32 · กลางวัน/กลางคืน (1 วัน = 20 นาที) มีแสงจากโคมไฟ/คบเพลิง/กองไฟ
- **เก็บทรัพยากร**: ขวาน→ต้นไม้, อีเต้อ→หิน (ได้แร่), มือ→เบอร์รี่/ดอกไม้/เห็ด · ต้นไม้/หินงอกใหม่เอง
- **สร้างบ้าน**: ผนังไม้/หิน/อิฐ หน้าต่าง ประตู รั้ว พื้น 5 แบบ + เฟอร์นิเจอร์แบบ Sims (เตียง เก้าอี้ โซฟา โต๊ะ ทีวี ตู้เย็น เตา โคมไฟ ชั้นหนังสือ อ่างอาบน้ำ ชักโครก คอมพิวเตอร์ น้ำพุ ...) · ของใครของมัน คนอื่นรื้อไม่ได้ · ป้ายเขียนข้อความได้
- **ปลูกผัก**: จอบพรวนดิน → เมล็ด 8 ชนิด → รดน้ำ (โตเร็ว 2 เท่า) → เก็บเกี่ยว (บางชนิดออกผลซ้ำ) · ทำอาหารที่เตา/กองไฟ
- **ชีวิตแบบ Sims**: เลือด (HP) + ความอิ่ม/พลังงาน/ความสนุก/ความสะอาด · หิวหรือหมดแรงถึง 0 เลือดจะลด เลือดหมด = เป็นลม ถูกพากลับบ้านและเสียเหรียญ 10% · ค่าหยุดลดเมื่อไม่ได้เล่นเกิน 2 นาที · นอน นั่ง ดูทีวี อ่านหนังสือ อาบน้ำ กิน
- **เลเวล & ยุคสมัย**: ได้ XP จากทุกกิจกรรม → ปลดล็อกสูตรคราฟต์/ของในร้าน ตั้งแต่ **ยุคหิน → สำริด-เหล็ก → ยุคกลาง → อุตสาหกรรม → ปัจจุบัน**
- **ยานพาหนะ**: แพ เรือพาย ม้า จักรยาน มอเตอร์ไซค์ รถยนต์ เรือเร็ว เฮลิคอปเตอร์ (บินข้ามทุกอย่าง)
- **ร้านค้า** ซื้อเมล็ด/เครื่องมือ ขายผลผลิต · **คราฟต์** 46 สูตร
- **เพื่อน & แชตแบบ Facebook**: ค้นหาชื่อผู้ใช้ → ส่งคำขอ → แชตส่วนตัว (หน้าต่างแบบ Messenger, badge ข้อความใหม่, ประวัติเก็บถาวร) · วาร์ปไปหาเพื่อน · แชตใกล้ตัว (bubble เหนือหัว) / ทั่วโลก
- **แผนที่ใหญ่/มินิแมป** แสดงตัวเอง บ้าน เมือง และเพื่อน · รองรับจอสัมผัส (จอยสติ๊ก)

## ปุ่ม

WASD/ลูกศร เดิน · Shift วิ่ง · คลิกซ้าย/Space ใช้ไอเทมที่เลือก · คลิกขวา/E มือเปล่า · 1-8/ล้อเมาส์ เลือกช่องด่วน · I กระเป๋า · C คราฟต์ · B ร้านค้า · F เพื่อน · M แผนที่ · L ยุค · H กลับบ้าน · V ลงจากพาหนะ · Enter แชต · Esc เมนู · Ctrl+ล้อเมาส์ ซูม

## โครงสร้าง

```
server/index.js   HTTP (auth, static, /api/map) + WebSocket game server + game loop
server/world.js   noise terrain, chunk gen/persist, crops/regrowth tick
server/db.js      JSON persistence (data/: users, players, chunks, dm, chat)
public/js/defs.js ไอเทม/แผ่นพื้น/สูตร/พืช/ยุค/พาหนะ (ใช้ร่วม server+client)
public/js/sprites.js  pixel art ทั้งหมด (procedural)
public/js/game.js     เอนจิน: chunk cache, render, แสง, input, พาหนะ
public/js/ui.js       HUD, กระเป๋า, คราฟต์, ร้าน, เพื่อน, แชต, แผนที่, ยุค
public/js/main.js     auth + character creator + lifecycle
```

ข้อมูลผู้เล่น/โลกเก็บที่ `data/` (สร้างอัตโนมัติ, ไม่เข้า git)

## กติกา UI

- **ห้ามใช้อิโมจิ** ทุกที่ในเกม (ปุ่ม ป้าย ข้อความแจ้งเตือน และที่วาดบน canvas) ใช้ไอคอน pixel ที่วาดด้วยโค้ดใน `public/js/sprites.js` (`UI_MAPS` → `Sprites.uiIcon(name)`) หรือข้อความล้วน สัญลักษณ์ตัวอักษรอย่าง ✕ ★ ➤ ใช้ได้
